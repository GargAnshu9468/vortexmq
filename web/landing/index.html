Lock-Free Circular Rings

Power-of-two circular buffers with atomic index pointers achieve 5.98ns operations with 0 B/op heap allocation on hot paths.

💾

Segmented WAL Durability

Append-only commit logs with IEEE CRC32 checksums guarantee zero data loss and over 640,000 durable disk commits per second.

🛡️

1-Click Dead Letter Replay

Poisoned or crashed tasks are automatically routed to the DLQ. Inspect payloads, failure stack traces, and replay them with 1-click.

🔌

Drop-in Redis Protocol

Zero migration friction. Connect with existing Redis clients in Python, Go, Node, or Java using LPUSH, RPOP, and BRPOP.

⏱️

Hierarchical Timing Wheel

O(1) message scheduling for delayed tasks and exponential backoff retries without min-heap lock contention.

🌌

Quantum Web Studio

Embedded on port 8380. Features animated SVG pipeline flows, real-time consumer lag graphs, dark/light theme, and direct publisher.
